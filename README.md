# SMS IT Agency — ডায়নামিক সাইট + অ্যাডমিন প্যানেল

ছোট Node.js সার্ভার (কোনো npm প্যাকেজ লাগে না)। সাইটের সবকিছু অ্যাডমিন প্যানেল (`/admin`) থেকে বদলানো যায়।

## অ্যাডমিন থেকে যা করা যায়
- **অর্ডার:** ফর্ম থেকে আসা অর্ডার দেখা, স্ট্যাটাস বদলানো (নতুন/চলছে/সম্পন্ন/বাতিল), নোট লেখা, WhatsApp/ফোন করা
- **সেকশন / সার্ভিস:** Facebook Ads, Facebook Follow ও প্রমোশন, ভিডিও এডিটিং, ওয়েবসাইট, এসইও… যেকোনো নতুন সেক্টর যোগ/সম্পাদনা/লুকানো/মোছা
- **কাজ / প্রজেক্ট:** প্রতিটি সেকশনের ভেতরে ছবি বা ভিডিও আপলোড করে নতুন কাজ যোগ
- **পেজ:** নতুন পেজ (লিংক `/#/p/নাম`), চাইলে মেনুতে
- **সেটিংস:** লোগো, হিরো ছবি ও লেখা, সম্পর্কে, স্লোগান, WhatsApp/Messenger/Facebook/ইমেইল/সোশ্যাল লিংক
- **ব্যাকআপ:** ডেটা ডাউনলোড ও ফিরিয়ে আনা

## যেকোনো হোস্টিংয়ে চালু করা
সব জায়গায় নিয়ম একই: কোড GitHub-এ রাখুন, দুটি Variable দিন (`ADMIN_PASSWORD`, `DATA_DIR`), আর `DATA_DIR` পাথে একটি **স্থায়ী ডিস্ক/Volume** জুড়ুন। ডিস্ক না থাকলে রিস্টার্ট বা নতুন ডিপ্লয়ে অর্ডার ও আপলোড করা ছবি-ভিডিও মুছে যায়।

**Railway:** New Project → Deploy from GitHub repo → Volume যোগ করুন (Mount path `/data`) → Variables: `ADMIN_PASSWORD`, `DATA_DIR=/data` → Settings → Networking → Generate Domain।

**Render:** New → Blueprint → রিপোজিটরি বেছে নিন (`render.yaml` আছে)। অথবা New → Web Service: Runtime Node, Start Command `node server.js`, Disk যোগ করুন (Mount path `/data`), Variables একই। Render-এ Disk শুধু পেইড প্ল্যানে।

**অন্য যেকোনো জায়গা (VPS, Fly.io, Koyeb…):** `Dockerfile` দেওয়া আছে। `/data` ভলিউম জুড়ে `ADMIN_PASSWORD` দিয়ে চালান।

অ্যাডমিন: `আপনার-ডোমেইন/admin`

**Render-এ এক ক্লিক ডিপ্লয় লিংক:** `https://render.com/deploy?repo=আপনার-GitHub-রিপোজিটরির-লিংক` ব্রাউজারে খুলুন। পরে কোড বদলালে GitHub-এ আপলোড করলেই অটো ডিপ্লয় হয়।

## নিজের কম্পিউটারে টেস্ট (এক ক্লিকে)
১. একবার https://nodejs.org থেকে **LTS** ইনস্টল করুন। ২. ZIP-টি Extract করুন। ৩. **Windows:** `START-WINDOWS.bat` ডাবল ক্লিক। **Mac/Linux:** `START-MAC-LINUX.command` ডাবল ক্লিক।
ব্রাউজারে সাইট খুলবে। অ্যাডমিন: http://localhost:3000/admin, পাসওয়ার্ড `admin123` (শুধু লোকাল টেস্টের জন্য)।
টেস্ট করা ডেটা `data/` ফোল্ডারে থাকে; নতুন করে শুরু করতে ফোল্ডারটি মুছুন। লোকালের কনটেন্ট সার্ভারে নিতে অ্যাডমিন → ব্যাকআপ থেকে নামিয়ে সার্ভারে "ফিরিয়ে আনুন" করুন (আপলোড করা ছবি/ভিডিও আলাদা আপলোড করতে হবে)।

## ফোল্ডার
```
server.js        ব্যাকএন্ড (API, লগইন, আপলোড)
seed.json        প্রথমবারের ডিফল্ট ডেটা
public/          সাইট; public/admin/ অ্যাডমিন প্যানেল
data/            (অটো তৈরি) db.json ও uploads/
```
